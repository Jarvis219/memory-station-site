# Memory Station — website

Static pages for the iOS app **Memory Station (Trạm Ký Ức)**, served by GitHub Pages:

- Privacy Policy: https://jarvis219.github.io/memory-station-site/privacy/
- Support: https://jarvis219.github.io/memory-station-site/support/

Plain HTML + one stylesheet, no build step. These URLs are what App Store Connect and the app link to — keep the paths stable.
